# FitArc — Development Plan

## Week 1: Planning and Design
- Finalize project requirements.
- Design the mobile screens in Figma.
- Create a clickable prototype.
- Set up the GitHub repository.
- Complete project documentation.

**Deliverables:** Figma design, prototype, README, requirements, screen list, and development plan.

## Week 2: Flutter UI Development
- Set up the Flutter project.
- Build the seven screens.
- Create reusable widgets.
- Implement navigation and data passing.
- Add form validation and user feedback.
- Implement light and dark themes.
- Test the main navigation flow.

**Deliverable:** A working Flutter UI prototype.

## Week 3: Local Data and CRUD
- Configure Hive CE.
- Create the workout model and adapter.
- Implement Create, Read, Update, and Delete operations.
- Display saved workouts.
- Add workout search.
- Test data persistence and common errors.

**Deliverable:** A workout planner with local data storage and CRUD functionality.

## Testing Strategy
- Check navigation between screens.
- Validate required form fields.
- Test adding, editing, and deleting workouts.
- Verify saved data remains available after restarting the app.
- Test search and theme switching.

## Completion Goal
Deliver a simple, user-friendly Flutter workout planner with local storage and the core workout-management features.

**Current status:** Week 1 — Planning and design.

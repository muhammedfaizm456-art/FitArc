# FitArc — Workout Planner App

FitArc is a mobile workout planner designed to help users create, organize, and manage their workout routines.

## Features

- Create and manage workout plans
- View workout details, sets, reps, and duration
- Search workouts
- Edit and delete workouts
- Mark workouts as completed
- Light and dark themes
- Local data storage using Hive CE
- Account and profile settings

## Screens

1. Splash
2. Login
3. Home Dashboard
4. Workout Library
5. Add Workout
6. Workout Details
7. Account

## Technology Stack

- **Design:** Figma
- **Language:** Dart
- **Framework:** Flutter
- **Local Database:** Hive CE
- **Version Control:** Git and GitHub

## Development Plan

- **Week 1:** Documentation, UI/UX design, clickable prototype, and GitHub setup
- **Week 2:** Flutter UI, navigation, form validation, and state handling
- **Week 3:** Hive integration, CRUD operations, and workout search

## Project Status

Currently in the design and documentation phase.

## Scope

The first version focuses on managing personal workout data locally. Cloud synchronization, AI features, and real authentication are not included in the initial version.
